- 녹화하는 동안 자동 화질이 그림 크기를 0.60까지 내렸어요(5단계).
- 소리는 끊김 없이 저장돼요(40초 = 1,920,000샘플, `audioGaps` 0).
- **녹화 시간이 다 지나기 전에 앱이 꺼지면 `audio.wav`, `frames.csv`, `recording.json`이 저장되지 않아요.** 그림(JPEG)만 남아요. `RunRecorder`가 시간이 다 된 뒤에만 `Finish()`를 불러서예요. 1280x720 30장 칸이 비어 있는 것은, 처음에 `--quit-after`가 녹화보다 먼저 앱을 꺼서 이렇게 됐기 때문이에요.
