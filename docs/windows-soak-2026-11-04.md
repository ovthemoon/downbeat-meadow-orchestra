## 2. 감시 프로그램과 "스스로 끄기" (릴리스에서 Windows에 물어본 것)

1. **다시 켜진 횟수 0.** `logs\supervisor-20261104.csv`에는 `supervisor_start`와 `unity start` 두 줄만 있어요(11:43:27). 그 뒤로 `kill`, `exit`, `start` 줄이 없어요.
2. **`logs\exit-reasons.txt`는 생기지 않았어요.** 앱이 스스로 끈 적이 없어요. 그래서 종료 코드 71과 72는 이번에 볼 수 없었어요.
3. **Player.log에 `d3d11:` 줄이 없어요.** 그래픽 장치를 잃지 않았으니까요. 그래서 `(Filename:` 꼬리가 붙는지도 이번에는 확인하지 못했어요.
   - Windows 오류 보고 대기열에도 새 `LiveKernelEvent 141` 보고가 없어요. 가장 최근 것은 그대로 11-03 03:55 것이에요.
4. **`working_set_mb`가 0이 아니에요.** 480줄 모두 숫자가 있어요(361.0~383.1 MB). 같은 때 밖에서 잰 작업 메모리와의 차이는 평균 −0.1 MB, −6.9~+8.2 MB예요. 고친 것이 Windows에서 맞게 돌아요.
5. **끌 때.**
   - 닫기 신호를 보내고 3초 안에 꺼졌어요. 꺼질 때 적는 마지막 상태 기록 줄(19:43:28, `uptime_s` 28796.3)도 남았어요.
   - 감시 프로그램은 제가 `Stop-Process`로 껐어요(`run-supervised.ps1`이 종료 코드 −1로 끝남). 그래서 감시 기록에 끝 줄이 없어요. 고장은 아니에요.
