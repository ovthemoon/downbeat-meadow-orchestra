## 5. Windows 쪽이 고친 것

- `tools/windows/_common.ps1` `Confirm-YesNo` (eb52f3d): 키보드가 없을 때(입력이 다 떨어지면) `Read-Host`가 `$null`을 주는데, 예전 줄은 거기에 `Trim()`을 불러서 `play-with-hands.ps1`이 "You cannot call a method on a null-valued expression"으로 멈췄어요(카메라 확인이 Y/N을 물을 때). 이제 N으로 봐요. 이 스크립트들이 묻는 것(설치, 지우기, 이대로 앱 켜기)에서는 N이 안전한 답이에요. Windows PowerShell 5.1에서 입력 없음 → N, y → 예, 틀린 답 뒤 N → 다시 묻고 아니오를 확인했어요.
