## 2. 03:55에 멈춘 것

- 03:54:43: 마지막 상태 기록 줄. 정상이었어요(29.9장/초, 가장 긴 장 59.8 ms, 오류 0).
- 03:55:10.75: 마지막 heartbeat (`audio=ok`, `app=running`). 같은 초(03:55:10~11)에 Intel 그래픽 서비스(`igcc`)가 전원 이벤트를 처리했다고 Application 로그에 남았어요. 이 서비스는 22:50~22:51, 03:58, 04:40에도 전원 이벤트를 처리했는데, 무슨 이벤트인지는 로그에 없어요.
- 03:55:13: 107.7 ms 걸린 장 하나가 기록됐어요(앱이 적은 마지막 숫자).
- 앱 로그의 마지막 4줄: `d3d11: failed to create buffer (target 0x5 mode 0 size 96) [0x887A0005]`와 `(target 0x2 mode 0 size 12) [0x887A0005]`가 두 번씩이에요. `0x887A0005`는 `DXGI_ERROR_DEVICE_REMOVED`(그래픽 장치를 잃음)예요. 그 뒤로는 로그, 상태 기록, heartbeat가 하나도 없어요.
- 03:55:26: Windows 오류 보고가 `LiveKernelEvent` 코드 `141` 보고 하나를 만들었어요. 141은 그래픽 엔진 시간 초과(`VIDEO_ENGINE_TIMEOUT_DETECTED`)예요. GPU가 한동안 답하지 않아 Windows가 드라이버를 다시 시작한 것이에요.
- 아직 보내지 않은 보고 대기열에 141 보고가 다섯 개 더 있어요. 만들어진 때는 2026-07-22, 07-29(두 개), 08-19, 10-29 23:33이에요(폴더가 만들어진 시각).
  - 7~8월 것은 이 저장소가 생긴 10-29보다 몇 달 앞서요. 그러니 이 노트북에서는 이 앱이 없을 때도 그래픽 시간 초과가 있었어요.
  - 10-29 23:33 것은 Windows가 붙인 묶음 이름(`Kernel_141_ee7b4124…`)이 오늘 밤 것과 같아요. 그 밤은 이 노트북으로 처음 Windows 시험을 하던 때라 앱이 켜져 있었을 수 있지만, 확인하지는 못했어요.

## 3. 전시 구성이었다면

감시 프로그램의 Windows 설정(`supervisor/configs/windows.json`)은 `heartbeatTimeoutSec` 30이에요. heartbeat가 30초 넘게 오래되면 앱을 끄고 다시 켜요(`heartbeat_stale`). 그러니 세션 C처럼 감시 프로그램과 같이 돌았다면 03:55:40쯤 다시 켜졌을 거예요. 다만 이번에는 앱 혼자 돌렸기 때문에, 그래픽 드라이버가 다시 시작된 뒤 새로 켠 앱이 정상으로 도는지는 보지 못했어요.

## 4. Mac에 알릴 것

`unity/`와 `supervisor/`는 Mac 쪽이라 고치지 않았어요.

1. **그래픽 장치를 잃으면(`DXGI_ERROR_DEVICE_REMOVED`) 앱이 꺼지지도 되살아나지도 않고 멈춰요.** 닫기 신호에도 응답하지 않아요. 앱 혼자 돌리면 아침까지 멈춘 화면으로 남아요. `Scripts/`에 장치를 잃는 경우를 다루는 코드는 찾지 못했어요.
2. **GPU 시간 초과의 원인은 아직 몰라요.** 내장 Intel UHD, 드라이버 31.0.101.2141, Low 화질(풀 64,642장, 꽃 190, 반딧불 100까지), 6시간 57분에 한 번이었어요. 이 노트북에는 7월부터 같은 종류의 시간 초과 보고가 다섯 번 더 있어요(2절). 앱 탓인지 드라이버 탓인지 가르려면 같은 조건으로 한 번 더 돌리거나, 새 Intel 드라이버로 돌려 봐야 해요. 드라이버 설치는 사용자에게 먼저 물어봐야 해요.
3. **Windows에서는 `working_set_mb`가 늘 0.0이에요.** 이번 417줄이 모두 그렇고, 그 전 Windows 상태 기록도 모두 그래요. 같은 때 밖에서 잰 작업 메모리는 375~392 MB였어요.
4. **0.8초대 멈춤 두 번(22:52, 01:56)에는 소리 시계도 0.83~0.88초를 한 번에 건너뛰었어요.** 늦은 음은 0이었어요. 다만 소리를 끈 구동이라 실제로 들리는지는 몰라요.
