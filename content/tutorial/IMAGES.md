# 안내 화면의 손 그림

| 파일 | 내용 |
|---|---|
| `hand-open.png` | 편 손(손바닥이 보이게, 손가락 다섯 개를 편 손) |
| `hand-fist.png` | 주먹(손가락 마디가 보이게, 엄지가 앞을 감싼 주먹). 두 주먹 장면의 왼손은 앱이 좌우로 뒤집어 그려요. |

- 모양: 따뜻한 금빛 홀로그램이에요. 빛나는 외곽선, 옅게 비치는 안쪽 면, 부드러운 주사선, 작은 빛 알갱이로 이루어져 있고, 중심색은 #FFE7A6, 번지는 빛은 #F2B45A예요.
- 만든 방법: 2026-10-31, Codex CLI 0.162.1의 이미지 생성 기능(OpenAI)으로 1024x1024 투명 배경 PNG를 만든 뒤 512x512로 줄였어요. 다른 편집은 하지 않았어요.
- 권리: OpenAI 이용약관의 "콘텐츠의 소유권" 조항에 따라 출력은 이 프로젝트 만든 사람의 것이에요(같은 약관의 "콘텐츠 유사성" 조항대로 다른 사용자가 비슷한 그림을 받을 수는 있어요).
- 요청한 그림 설명(요약): 조용한 밤 들판 음악 설치물의 화면 안내용 아이콘, 금빛 홀로그램(빛나는 외곽선, 옅은 반투명 면, 부드러운 주사선, 작은 빛 알갱이), 손목까지만, 정면, 글자 없음, 투명 배경.
